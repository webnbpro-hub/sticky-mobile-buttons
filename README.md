== Description ==

**Boost Your Mobile Conversions with Floating Action Buttons!**

Sticky Mobile Buttons transforms your mobile visitors into customers by adding eye-catching floating buttons that stay visible while scrolling. Perfect for mobile-optimized websites!

= Why Choose Sticky Mobile Buttons? =

**Increase Conversions** - Make important actions always accessible  
**Mobile-First Design** - Automatically shows only on mobile devices  
**Fully Customizable** - Match your brand colors and style  
**Lightweight & Fast** - Won't slow down your website  

= Perfect For: =

- Contact buttons (Phone, WhatsApp, Telegram)
- Quick cart access for WooCommerce
- Link to important pages
- Special promotions or calls-to-action
= Features =
- Up to 7 customizable buttons
- Multiple button types: Phone, Telegram, WhatsApp, Cart, and custom links
- Visual icon selector with Font Awesome icons
- Custom icon upload support
- Color customization for each icon
- Show/hide text labels
- Responsive design - only shows on mobile devices
- Smooth animation effects

== Installation ==

= Automatic Installation =
1. Go to Plugins ? Add New in WordPress admin
2. Search for "Sticky Mobile Buttons"
3. Click "Install Now" and then "Activate"

= Manual Installation =
1. Upload the `sticky-mobile-buttons` folder to `/wp-content/plugins/`
2. Activate the plugin through Plugins menu
3. Go to Settings ? Sticky Buttons to configure

= Configuration =
1. After activation, visit Settings ? Sticky Buttons
2. Add your first button using the intuitive visual editor
3. Customize colors, icons, and positions
4. Save changes and test on mobile device

== Frequently Asked Questions ==

= How many buttons can I add? =
You can add up to 7 buttons.

= Can I use custom icons? =
Yes, you can choose from Font Awesome icons or upload your own custom images.

= Does this work with page builders? =
Yes, the plugin works with any WordPress theme and page builder.

= Does this work with WooCommerce? =
Absolutely! Add a direct cart button that shows item count.

= Will it slow down my website? =
No! The plugin is optimized for performance and loads only on mobile devices.

= Can I change button colors? =
Yes, each button can have custom background, icon colors, and hover effects.
